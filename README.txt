POAbooth revised website

Open index.html through a local web server or publish this folder on a static HTTPS host such as Netlify. Camera access requires HTTPS or localhost.

Updates: selected layout has a visible outline; camera preview and captured photos follow the selected 16:9 landscape or 9:16 portrait ratio; after one or more photos users can go directly to Customize or take the next shot; the strip renderer waits for images before drawing/exporting/printing; and Share Photos uses the device share sheet where supported. The QR code opens the hosted POAbooth website. It does not upload photos: a QR photo-download link requires a separate online file-storage backend.
